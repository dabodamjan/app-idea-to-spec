# Knowledge

This folder is app-idea-to-spec's playbook. The commands read these docs when they generate and pressure-test a spec, and you can read them on their own.

Everything here is written to be current as of 2026 and honest about what is unsettled. The mobile platforms change, so if something here has gone stale, see [CONTRIBUTING.md](../CONTRIBUTING.md).

| [monetization](monetization.md) | StoreKit 2 vs RevenueCat, paywall patterns, the 15% Small Business Program, the current regulatory picture |
